# AGENTS.md

## Project
This is a Python Streamlit project for tracking Buff.163 CS2 skin prices, storing price history, analyzing price changes, and displaying a dashboard.

## Main goal
Improve this project so it becomes a strong portfolio project for Data Analyst / Cloud Engineer / AI-related jobs.

## Tech stack
- Python
- Streamlit
- Pandas
- Plotly or Matplotlib
- Google Sheets API
- Optional: Discord / Email alert

## Rules
- Always inspect files before editing.
- Do not rewrite the whole project unless clearly necessary.
- Make small and safe changes.
- Preserve existing features.
- Do not hardcode API keys, cookies, passwords, Discord webhooks, or Google credentials.
- Use environment variables or Streamlit secrets for sensitive values.
- Handle network errors, missing data, and empty price listings safely.
- After editing, explain what changed and how to test.
